## My Tortuous Experience
On Friday night, I had a sudden urge to build a blog. I’d had this idea before, but I never actually acted on it.  
I had looked up some tech blogs before, and most of them were built with Hexo. So I found some tech blog tutorials on CSDN, read about how to build one, and had already chosen a theme—Butterfly. I got it set up in about half a day. The only annoying part was that I wanted to customize the UI, but Hexo couldn’t show changes in real time, so I searched online for relevant communities.  
In the community, I came across the Astro framework. It looked really good, so I started trying it out.
